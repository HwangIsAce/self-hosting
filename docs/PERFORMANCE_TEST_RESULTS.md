# vLLM 전환 성능 테스트 결과

## 테스트 환경
- 모델: Qwen/Qwen2.5-7B-Instruct
- GPU: RTX 4090 (24GB)
- 테스트 날짜: 2026-02-10

## HuggingFace 엔진 성능 (기준)

### 1. 단일 요청 성능 (5회 평균)
- **평균 시간**: 2.8초
- **처리 속도**: 47-52 tokens/sec
- **평균 토큰**: ~135 토큰

### 2. 배치 요청 성능 (10개 동시)
- **총 시간**: 10.17초
- **평균 시간/요청**: 1.02초
- **처리 속도**: 71.99 tokens/sec
- **총 토큰**: 732 토큰
- **처리 방식**: 순차 처리 (각 요청을 하나씩 처리)

### 3. Chunk Enrich 성능 (50개 chunk)
- **총 시간**: 299.48초 (약 5분)
- **평균 시간/chunk**: 5.99초
- **처리 속도**: 41.36 tokens/sec
- **총 토큰**: 12,387 토큰
- **처리 방식**: 순차 처리

## vLLM 엔진 예상 성능

### 이론적 개선 예상치

| 시나리오 | HuggingFace | vLLM 예상 | 개선율 |
|---------|------------|----------|--------|
| **단일 요청** | 2.8초 | 2.2-2.5초 | **10-20% 향상** |
| **배치 10개** | 10.17초 | 3-5초 | **2-3배 향상** |
| **Chunk 50개** | 299.48초 | 15-30초 | **10-20배 향상** |

### 예상 개선 이유

1. **단일 요청**: 
   - vLLM의 최적화된 커널 사용
   - PagedAttention으로 메모리 효율 향상
   - 약간의 성능 개선 (10-20%)

2. **배치 요청**:
   - Continuous Batching으로 동시 처리
   - GPU 활용도 극대화
   - 2-3배 성능 향상 예상

3. **Chunk Enrich**:
   - 50개 chunk를 동시에 배치 처리
   - 순차 처리 대비 극적인 성능 향상
   - 10-20배 성능 향상 예상

## 실제 사용 시나리오별 예상

### 시나리오 1: 단일 사용자 (대화형)
- **현재**: 질문당 약 2.8초
- **vLLM**: 질문당 약 2.2-2.5초
- **개선**: 약 0.3-0.6초 단축 (10-20% 향상)

### 시나리오 2: 여러 사용자 동시 사용
- **현재**: 순차 처리로 대기 시간 증가
- **vLLM**: 동시 처리로 대기 시간 감소
- **개선**: 동시 요청 수에 따라 2-3배 향상

### 시나리오 3: RAG Chunk Enrich (100개 chunk)
- **현재**: 100개 × 5.99초 = 599초 (약 10분)
- **vLLM**: 배치 처리로 약 30-60초
- **개선**: 10-20배 향상

## 결론

### 즉시 체감 가능한 개선
- ✅ **배치 처리**: 동시 요청이 많을수록 효과 큼
- ✅ **Chunk Enrich**: RAG 시스템에서 극적인 성능 향상
- ✅ **단일 요청**: 약간의 개선 (10-20%)

### 권장 사용 사례
1. **RAG 시스템**: Chunk enrich 시 10-20배 향상
2. **다중 사용자 환경**: 동시 요청 처리 시 2-3배 향상
3. **배치 작업**: 대량 데이터 처리 시 극적인 성능 향상
